# Bulk GSC Link Indexer – Chrome Extension

A Chrome Extension that automates bulk URL indexing requests on Google Search Console (GSC).

## Features
- Paste multiple URLs at once
- Automated click-through workflow on GSC
- Safety delay between requests (customizable)
- Real-time progress logs in a dark-mode popup UI
- Error handling: skips failed URLs automatically

## Installation
1. Download or clone this repository
2. Open Chrome → go to `chrome://extensions/`
3. Enable **Developer Mode** (top right)
4. Click **Load unpacked**
5. Select this folder

## Usage
1. Open [Google Search Console](https://search.google.com/search-console)
2. Click the extension icon in your toolbar
3. Paste your URLs (one per line)
4. Set your preferred delay (seconds)
5. Click **Start**

## ⚠️ Disclaimer
This extension automates actions on Google Search Console.
Use responsibly. Too many rapid requests may trigger rate limits or CAPTCHAs.
